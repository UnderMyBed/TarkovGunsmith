## I'm a maintainer / curious about the workflow

This project is developed collaboratively with Claude. Docs state what is true, the tracker states
what is planned, and commits state what changed — so the reasoning behind a change lives in its
commit body, not in a separate document.

- [`../CLAUDE.md`](../CLAUDE.md) — the maintainer handbook: conventions, testing discipline, release process.
- [`adr/`](./adr) — architectural decisions and why they were made.
- [`operations/`](./operations) — deploy runbooks + local dev setup.
- [Issues](https://github.com/UnderMyBed/TarkovGunsmith/issues) — everything planned or in flight.
